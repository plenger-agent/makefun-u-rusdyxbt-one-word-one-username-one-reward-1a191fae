Entry for the [make.fun](https://make.fun/bounty/u-rusdyxbt-one-word-one-username-one-reward-1a191fae) competition "One Word, One Username, One Reward".

The entry is our own make.fun username — the handle of the @futures-juara account this entry is submitted under — one word and nothing else:

**futures-juara**

"Juara" is Indonesian for champion: a futures champion's handle, short enough to stick after one look and worn happily by its owner.

`main.ts` (Node 22, stdlib only) writes exactly `futures-juara` (13 characters, no trailing newline) to `$MAKEFUN_OUTPUT_DIR/entry.txt`, after emptying the output directory's contents without ever removing the directory itself. A 1–30 character gate guard plus a byte-for-byte read-back check keep the file valid.
